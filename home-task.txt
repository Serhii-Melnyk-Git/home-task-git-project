1. Відкрити термінал у редакторі.
2. Прописати "--version" щоб перевірити чи git підключений.
3. "git init" створюю новий локальний репозиторій у поточній папці.
4. "git config --global user.name "..."" Встановлення імені для автора git комітів на компютері.
5. "git config --global user.email "..."" Встановлення електроної пошти для автора.
6. Додати вайли та папки до проекту щоб було з чим працювати.
7. Створюємо файл ".gitignore" в корневій папці. У цьому завдані в нас були такі файли і папки 
    "всі файли з розширенням .sass та папки: bin, admin, config." також додав сам файл ".gitignore" .
8. За допомогою команди "git add ." вивантажуємо всі файли з даного проекту, за виключенням файлів і папок, які внесені до файлу ".gitignore".
9. Перевіряю за командою "git status" чи файли готові до коміту. 
10. За командою "git commit -m "..." " комітемо всі файли та додаємо коментар у лапках , щоб розуміти інформацію про зміни.
11. Через команду "git status" можна перевірити чи були вивантажені фали та папки до локального репозиторію.
12. Командою "git branch blog-1.0" створюю нову гілку "blog-1.0". 
13. Командою "git checkout blog-1.0" переходжу на цю гілку.
14. Через команду "git status" можна перевірити чи змінили ми гілку.
15. Створюю папку "blog" з файлами: "index.js, index.html" в корневій папці.
16. За допомогою команди "git add ." вивантажуємо всі файли з даної гілкию. 
17. За командою "git commit -m "..." " комітемо все із гілки, додаємо коментар.
18. Повертаємося на основну гілку "git checkout master".
19. Створюємо GITHUB account. 
20. Підключаємо акаунт до нашого проекту в консолі за допомогою "git remote add origin https://github.com/Serhii-Melnyk-Git/home-task-git-project.git"
21. Перевіряємо "git remote"
22. Вивантажуємо спочатку весь проект у локальний репозиторій.
